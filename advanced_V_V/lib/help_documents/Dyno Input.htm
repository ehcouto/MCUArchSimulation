Dyno Input

Description

This Matlab function block is used to input Dyno load.



















Input

The Speed_attained is input signal coming from the speed attained block.

Output

1. Dyno Input is the dyno load torque signal generated as per user defined value.

2. Dyno_applied is status signal generated once dyno load torque has been applied.

Parameters
























This block contains two configurable Parameters which are configured through the parameter initialization file:
Dyno Load Value
It is the dyno load torque value defined by the user.
Dyno Step Size
It is the value assigned to generate the ramp input of dyno load before reaching stable value.

Working






























In above figure there are two graphs ,one depicts Dyno Input signal and other is Dyno attained status.

Once the Speed_attained signal is activated, that is logic 1. Dyno Input signal will start generating a ramp (Dyno Step Size) signal till

its value reaches to Dyno Load Value.Once reach Dyno Load Value in the signal,

Dyno_applied will give logic 1 signal. Dyno_applied status may be send to other functions to begin their executions.
