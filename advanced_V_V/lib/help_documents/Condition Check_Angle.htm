Condition Check_Angle

Description

This Matlab function block is used to keep check on failure of the test.



















Input

1. Time is real simulation time,which is used to calculate failure conditions.

2. Speed_Plant is the output speed from the plant.

3. Speed_Ref is the given reference speed by the user.

4. Dyno_Applied is the status to know whether Dyno load is applied or not.

4. Target_Speed is the target speed defined by the user.


Output

1. The output Condition_Check_1 will keep check on startup conditions.The signal will go high if start up is Bad.

2. The output Condition_Check_2 will keep check on startup conditions.The signal will go high if start up is Worse.

3. The output Fail_ Condition_1 will send the signal to stop the simulation if failure condition is true, which is due to out of bound response.

4. The output Fail_ Condition_2 will send the signal to stop the simulation if failure condition is true, which is due to oscillatory response.

Parameters























The block contains 5 configurable Parameters which are configured through the parameter initialization file:
Speed Tolerance Value
It is value in % which defines the speed tolerance band beyond which speed is considered to be failure(for Failure_1 condition).
Parameter Time Check_1
It is the time in sec , which is used in condition block to check if the speed is unbounded for more than para time check_1(for Failure_1 condition).
Parameter Time Check_2
It is the time in sec , which is used in condition block to check if the speed is unbounded for more than para time check_2 (For Startup condition).
Parameter Time Check_3
It is the time in sec , which is used in condition block to check if the speed is unbounded for more than para time check_3(For Failure_2 condition)
Speed_Tolerance_1
It is value in % which defines the speed tolerance band beyond which speed is considered to be failure(For Failure_2 condition).

Working

























In order to keep check on failure condition,Time has to synchronise with real time simulation.Time is connected through clock as an input to the block

Condition check will begin only when the Dyno_applied signal is high.

If the difference in Speed_Plant and Speed_Ref is within the vicinity of tolerance band, output to stop simulation is logic 0.

If the difference is not within the tolerance and if speed continues to go out of limit for time greater than Parameter Time Check_1, output to stop simulation is logic high.

Startup conditions has been analysed and defined as bad and worse start up. If the speed is out of bound or shows small peaks or jerks for time equal to Para Time check_2, than counter will increment 1.

And this condition is defined as bad startup. If the speed is out of bound or shows small peaks or jerks for time more than para time check_2 , than counter will further increment.

This condition is defined as Worse startup.

Both above conditions are checked, if speed from plant is greater than or equal to Target speed. Fail Condition_2 has been check when plant speed greater than or equal to target speed and speed is more than Speed Tolrance_1 value

and shows oscillatory response.This condition will define as Fail_2.
