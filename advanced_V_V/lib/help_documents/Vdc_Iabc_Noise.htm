Vdc & Iabc Noise Input

Description

This Matlab function block is used to input noise on Vdc voltage and Iabc currents .



















Input

1. Time is real simulation time,which is used here to generate noise signal.

1. Dyno input is status coming from Dyno load block, illustrating that Dyno load has been applied and now its ready to impose noise.

Output

1. V_Noise is output signal which is added to Vdc noise.

2. Ic_Noise is output signal which is added to Iabc noise.

Parameters

























This block contains four configurable parameters which are configured through the parameter initialization file:
Initial Value
It is the initial value of the noise power which is going to vary.(i.e Vdc or Iabc).
Time_Check
Generation of noise input signal will begin after Para time check(sec) that is,once Dyno load input is stable after Para time check noise input signal begins.
Percentage Variation
It is the percentage by which noise level will increment at every step.
Selection of Test
It will give logic 1 for selection of test carried by imposing voltage noise, and logic 0 when it is noise on currents.

Working with example





























Noise signal gets activated once dyno load has been applied, that is once its status is high.

Noise on Voltage(Vdc) and Current(Iabc) will vary depending on the corresponding change in noise power level.

Volt and Iabc port will generate stepwise increasing noise level output, which are fed to matlab function to generate White noise

In case if test is performed by adding voltage noise, V_Noise will have output containing noise to be added with Vdc input of ADC block.

In case if test is performed by adding current noise, Ic_Noise will have 3 output noise to be added with Iabc input of ADC block.

Depending on the selection of test that is either carried by adding noise on voltage or currents, Volt and Iabc port will generate signal.

If the test is carried for voltage noise,than noise on Currents is always zero and vice versa

This test is carried for testing performance of sBPM motor, by adding noise on Voltage and currents.

File

This test is supported by two .m files, one for parameter initialization 'Parameter_Initialization_ADC.m' and other one to run the script 'Automatic_script_ADC.m'.

Test named 'Harness_ADC_Noise.slx' and can be found in the 'Sim_Arch\Harness' folder.
